# API de Restaurante - ASP.NET Core

Esta é uma API RESTful desenvolvida com **ASP.NET Core** para gerenciamento de **menu** e **pedidos** em um sistema de restaurante/lanchonete.

---

## Como rodar o projeto

### Pré-requisitos

- [.NET 8 SDK]

### 🔧 Passos para rodar localmente

```bash
# Clone o repositório
git clone https://github.com/rodrigocros/GoodHamburguer.API/tree/master
cd seu-repo

# Compile o projeto
dotnet build

# Execute a aplicação
dotnet run

A API estará disponível em:
[https://localhost:5001 ou http://localhost:5000](https://localhost:7088/swagger/index.html)
